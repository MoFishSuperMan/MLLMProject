\begin{abstract}
面向 PDF、扫描文档和图表型页面的问答任务，传统纯文本 RAG 容易丢失版面结构、图表数值和视觉区域位置，导致证据定位与回答生成不稳定。本文实现了一个多模态检索增强生成系统，支持 PDF/图片上传、页面渲染、结构化 chunk 构建、文本-图像统一 embedding、向量检索、Reranker 重排、GRPO 决策模型、多模态回答生成以及前端 PDF 证据高亮预览。

系统后端基于 PyMuPDF 完成页面解析、区域裁剪和表格 Markdown 生成，使用 BGE-M3 构建文本向量表示，使用轻量视觉特征或 Native ViT 形成图像向量，并通过统一 embedding 接口组织多源 evidence。检索阶段结合向量索引与 BGE-reranker-v2-m3 筛选证据，生成阶段使用 Qwen3-VL-8B-Instruct 理解图表、表格、广告和局部视觉区域。前端采用 FastAPI 与 React 实现文件管理、问答交互、连续 PDF 预览和 bbox 高亮溯源。

实验在 DocVQA 与 ChartQA 任务上比较 Text-RAG 与 Our-RAG。结果表明，Our-RAG 总体 EM 和 ANLS 均达到 0.9750，显著高于 Text-RAG 的 0.3750 和 0.4265；消融实验进一步说明 Reranker、统一多模态向量化和 GRPO 决策模型对结果具有贡献。本文最后总结了复杂表格行列对齐、区域裁剪、视觉检索和长文档处理等后续优化方向。

\keywords{多模态大模型, 检索增强生成, 文档理解, DocVQA, ChartQA, Qwen3-VL}
\end{abstract}
