\chapter{绪论}

\section{任务定义与任务背景}

本项目旨在构建一个集文档解析、视觉定位、检索增强生成和自然语言理解于一体的多模态文档智能问答系统。系统面向 PDF、图片等非结构化文档，能够识别和理解其中的文本、表格、公式、图表和局部视觉区域，并通过多模态 RAG 实现长文档精准检索与结构化问答。同时，系统需要在回答中保留可溯源信息，使用户能够回到原始页面检查答案对应的页码、chunk 和视觉区域。

核心任务主要包括以下三个方面：

\begin{itemize}
  \item \textbf{多模态 RAG 架构构建}：建立统一的文档解析与证据组织流程，将文本语义、表格结构、图像区域和页面坐标组织为可检索 evidence，使不同模态的信息能够进入同一套问答流程。
  \item \textbf{模型选择与自动决策}：通过 GRPO 强化学习训练决策模型，根据用户问题、候选证据和历史奖励选择合适的 LLM/VLM 与上下文组织方式，从而提高不同类型问题下的回答稳定性。
  \item \textbf{可解释性溯源}：在生成回答的同时，保留证据编号、页码、chunk 信息和 bbox 区域，使前端能够在连续 PDF 预览中高亮对应位置，避免系统只输出不可检查的文本答案。
\end{itemize}

在企业办公、科研阅读和课程资料检索等场景中，真实知识往往并不只存在于纯文本中，而是分布在 PDF 页面、表格、图表、扫描件、截图和复杂版面结构中。传统 RAG 主要针对纯文本数据设计，通常需要先通过 OCR 或文本抽取把文档转为线性文本，再进行向量检索和生成回答。这种流程在普通段落问答中较为有效，但面对图表数值、表格行列关系、广告标签、票据版面和局部视觉信息时，容易丢失页面结构和视觉语义。

随着多模态大语言模型的发展，模型已经能够直接读取页面图像、局部区域和图表结构，为复杂文档问答提供了新的技术路径。因此，本项目围绕“文档解析-多模态证据检索-GRPO 决策模型-生成回答-PDF 高亮溯源”构建完整系统，并通过 DocVQA 和 ChartQA 任务对 Text-RAG 与 Our-RAG 的效果进行比较，验证多模态证据在文档理解问答中的作用。
